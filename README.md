# Student Information System (Python)

## Project Overview
A command-line Student Information System developed using Python. This project allows users to manage student records and save information in a CSV file.

## Features
- Register new students with their name, age, and three grades
- Automatically calculate average grades
- Classify students as Excellent, Good, or Needs Improvement
- View all student records
- Search for students by name
- Update existing student information
- Delete student records
- Save and load student data using CSV files

## Technologies Used
- Python 3
- Jupyter Notebook
- CSV file handling
- Visual Studio Code

## Python Concepts
- Functions
- Lists and dictionaries
- Loops and conditional statements
- User input
- File handling

## Grading Categories
- Excellent: 90 or higher
- Good: 70 to below 90
- Needs Improvement: Below 70

## How to Run
1. Download the repository files.
2. Open `Student_Information_System.ipynb` in VS Code or Jupyter Notebook.
3. Keep `students.csv` in the working directory.
4. Run the notebook cells in order.
5. Follow the menu instructions to manage student records.

## Project Files
- `Student_Information_System.ipynb` — Main Python program
- `students.csv` — Sample student records
- `README.md` — Project documentation
